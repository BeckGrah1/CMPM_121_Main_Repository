# Goal of this class project

This project was made in Unity with the goal of making a game that was easily modifiable and learning how to structure large software programs. This project was modified week by week adding new changes that built off of old ones. The fully completed version can be played on itch.io here

# Framework for CMPM 121

This framework is for the class CMPM 121 - Game Development Patterns. It was developed in Unity version 6000.0.23f, but should also work in other Unity versions.
